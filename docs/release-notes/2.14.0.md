## Improvements

- Fixed the indicator showing an outdated input source or color after changes made by other apps, by [@olsklcode](https://github.com/olsklcode) in [#146](https://github.com/runjuu/InputSourcePro/pull/146).
- Fixed missing indicator updates when switching apps or websites, by [@runjuu](https://github.com/runjuu) in [#146](https://github.com/runjuu/InputSourcePro/pull/146).
- Fixed the wrong input source being remembered for an app when using the "Shortcut Simulation" fix, by [@runjuu](https://github.com/runjuu) in [#146](https://github.com/runjuu/InputSourcePro/pull/146).
- Fixed input source colors no longer following global settings after opening customization or changing just one color. Renamed the reset action to "Use Global Colors", by [@runjuu](https://github.com/runjuu).
