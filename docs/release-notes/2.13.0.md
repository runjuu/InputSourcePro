## What's new

- Added optional Caps Lock status to the input source indicator, with a setting to show it when Caps Lock changes, by [@runjuu](https://github.com/runjuu).
- Added "Additional cursor support" to help the indicator follow the text cursor in more apps. Available under Position → Advanced; requires Enhanced Mode and Cursor Helper setup, by [@runjuu](https://github.com/runjuu).
- You can now receive beta updates, by [@runjuu](https://github.com/runjuu).

## Improvements

- The always-on cursor indicator now works independently of the default indicator's position and triggers, by [@runjuu](https://github.com/runjuu).
- Improved indicator positioning in JetBrains editors and search fields, by [@runjuu](https://github.com/runjuu).
- Reduced indicator flicker, jumps, and overlapping labels when switching input sources, by [@runjuu](https://github.com/runjuu).
- Fixed unwanted indicator appearances when triggers are disabled, improved behavior after sleep and screen locking, and reduced background mouse monitoring and timer wakeups, by [@gum798](https://github.com/gum798) and [@runjuu](https://github.com/runjuu) in [#141](https://github.com/runjuu/InputSourcePro/pull/141).
- Added shortcut conflict messages that identify the conflicting setting and preserve the previous shortcut, by [@Vivapercuore](https://github.com/Vivapercuore) and [@runjuu](https://github.com/runjuu) in [#134](https://github.com/runjuu/InputSourcePro/pull/134).
- Fixed modifier shortcuts becoming unresponsive after missed key releases and improved shortcut monitor cleanup, by [@rstuckert](https://github.com/rstuckert) in [#138](https://github.com/runjuu/InputSourcePro/pull/138) and [#139](https://github.com/runjuu/InputSourcePro/pull/139).
- Improved settings responsiveness and made the "Enhanced Mode Required" badge clickable to enable the feature, by [@runjuu](https://github.com/runjuu).
